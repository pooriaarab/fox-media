# agentic-reply — 90s multi-cam sitcom / couch set

World 08/20. No VO. 10 shots, ~22 s. Hard cuts.

Premise (true, repo desc): answer inbound
comments with human approval. Approval is the
proof beat; never show auto-send as default.

## Style anchor

AN: "warm 90s multi-cam sitcom, studio wash,
laugh-track glow, big couch set, sweater
neighbor, phone buzzes on cushion, plant, lamp"
NEG: N0 + no single-cam grit, no dark noir.
Hero: same neighbor, 3/4, knit sweater, age
30s. One ref, all shots edit it.
Prop: phone. Buzzing face-down in shot 3,
sent-check face-up in shot 8.
