## 5. Tesseract by Mirage — verdict

What: free agent-driven creative engine (mirage.app/tesseract). The agent edits a live project (text, shapes, masks, keyframes, adjustment layers, sound) and renders on macOS, Windows, or Linux. Adobe project import; ChatGPT plugin.
Cost: engine binary free; agent subscription or usage billed apart. Engine source closed; check the release license for commercial use.
Access: runtime API plus project schema bundled per release (github.com/mirage-hq/Tesseract); plugin or skills install; verify checksum, render a test preview. No standalone CLI shown — the agent drives it.
Fits: template-driven waves (this one), social ads, kinetic-type explainers, shared brand graphics across 20 cuts. Weak for: one-off hand art, heavy VFX.
Verdict: good fit as the motion engine behind an agent pipeline. Keep the hyperframes build for final assembly until a pilot passes audit.py.
